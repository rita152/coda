# Third-party notices

`@coda/plugins` composes the private `@coda/skills` and `@coda/mcp` packages. `@coda/skills` uses the ISC-licensed
[`yaml`](https://github.com/eemeli/yaml) package for data-only YAML parsing. `@coda/mcp` uses the official Model
Context Protocol TypeScript SDK, whose applicable license texts and dependency versions are recorded with that
package and in the repository lockfile.

`@coda/plugins` does not copy or bundle third-party source code. The complete notices distributed by its workspace
dependencies remain authoritative.
