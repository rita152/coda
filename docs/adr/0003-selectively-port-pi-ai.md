# Selectively port the Pi AI compatibility surface

Coda will selectively port the contracts, complex stream behavior, Api adapters, and tests needed by the frozen Pi AI compatibility profile instead of either independently rediscovering every behavior or copying the entire package. Coda is MIT licensed; copied or substantially derived material will retain the upstream MIT copyright and license notice both at the file and repository-notice level, and ported tests will identify their source baseline.
